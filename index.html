Aprende paralelismo ejecutando código real

Telar es un simulador educativo de OpenMP con PyOMP. Lee las lecciones, escribe tu código, ejecútalo en paralelo de verdad y observa el speedup en vivo. Funciona en tu equipo, sin cuenta ni conexión a un servidor externo.

Ver descargas

Necesitas Docker instalado y en ejecución. Telar ejecuta el código de cada estudiante dentro de contenedores aislados, así que Docker es obligatorio en los dos sistemas. Si no lo tienes, instálalo antes: Docker Desktop en Windows, Docker Engine en Linux.

Cómo instalarlo

Elige tu sistema. Son cuatro pasos y solo hay que hacerlos una vez.

  1. Instala Docker Desktop

    Descárgalo de docker.com, instálalo y déjalo abierto. Telar no puede funcionar sin él.

  2. Descarga el instalador

    Usa el instalador de la sección de arriba. La versión portable sirve si no puedes instalar programas en el equipo.

  3. Ejecútalo y acepta la advertencia

    Windows mostrará «Windows protegió su PC». Pulsa Más información y luego Ejecutar de todas formas.

    Aparece porque la aplicación no está firmada con un certificado de código comercial, que tiene un coste anual fuera del alcance de un proyecto académico. Puedes comprobar que el archivo es el correcto con los checksums.

  4. Abre Telar

    El primer arranque descarga cerca de 1 GB y tarda varios minutos: está bajando el servidor y el entorno de ejecución. Solo pasa la primera vez.

  1. Instala Docker Engine

    Sigue la guía oficial de tu distribución en docs.docker.com.

  2. Añade tu usuario al grupo docker

    Sin esto Telar no puede levantar los servicios, porque no tiene permiso para hablar con el demonio de Docker.

    sudo usermod -aG docker $USER

    Después hay que cerrar sesión y volver a entrar para que el cambio surta efecto.

  3. Instala el paquete

    Con el .deb, que es la opción recomendada:

    sudo apt install ./telar-desktop.deb

    Si prefieres el AppImage, que no instala nada, hay que darle permiso de ejecución: los navegadores no lo conservan al descargar.

    chmod +x Telar.AppImage && ./Telar.AppImage

  4. Abre Telar

    Con el .deb queda en el menú de aplicaciones. El primer arranque descarga cerca de 1 GB y tarda varios minutos: está bajando el servidor y el entorno de ejecución. Solo pasa la primera vez.

Si el AppImage no arranca En instalaciones mínimas puede faltar alguna librería del sistema. Con libfuse.so.2, instala libfuse2. Con libasound.so.2, instala libasound2t64 (o libasound2 en Ubuntu anteriores a la 24.04). El formato AppImage no puede declarar dependencias, por eso hay que ponerlas a mano. El .deb no tiene este problema y por eso es el recomendado.

Requisitos y notas

Qué necesita tu equipo Windows 10 u 11 de 64 bits, o Linux de 64 bits (x86-64). Docker instalado y en ejecución. 8 GB de RAM recomendados. No hay versión para macOS.

La primera ejecución de código tarda unos segundos Es la compilación JIT de PyOMP, que traduce tu Python a código máquina paralelo. Las siguientes ejecuciones son rápidas.

Telar se administra solo Al abrir la aplicación arranca sus servicios, y al cerrarla los detiene, para no dejarlos consumiendo recursos en segundo plano. También puedes controlarlos a mano desde el indicador de estado del menú lateral.

Verificar la descarga

Opcional, pero es la forma de comprobar que el archivo que bajaste es exactamente el que se publicó.

Ver los checksums SHA-256

En Linux, con el archivo de sumas descargado junto a los instaladores:

sha256sum -c SHA256SUMS.txt

Ese archivo lista los ejecutables de Windows con espacios en el nombre, pero GitHub los entrega con puntos, así que -c solo casa con los dos artefactos de Linux. Para los .exe, compara a mano con la tabla de abajo.

En PowerShell, archivo por archivo:

Get-FileHash "Telar Setup.exe" -Algorithm SHA256
